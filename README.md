# 🇪🇬 Egypt Real Estate Analytics Dashboard

## 📌 Project Overview
This repository features a fully interactive **Egypt Real Estate Analytics Dashboard** built from scratch using web technologies (**HTML5, CSS3, JavaScript, and Chart.js**). The primary purpose of this project is to provide deep commercial insights into the Egyptian property market, visualizing price distributions, property sizes, bedroom configurations, and developer market shares across premium locations like New Cairo, New Capital, Mostakbal City, and October.

---

## 🤖 AI-Powered Data Engineering
A core highlight of this project is the integration of **Artificial Intelligence (AI)** within the data engineering pipeline:
* **AI-Driven Data Structuring:** Generative AI tools and custom LLM prompts were leveraged to parse, clean, and structure unstructured or semi-structured Egyptian real estate listings into standardized, high-quality JSON data formats.
* **Feature Standardization:** AI was used to uniform complex text inputs, handle missing data points, and categorize raw property descriptions into clear-cut dimensions (e.g., standardizing custom room counts into structured categories like '1+Maid', '2 BR', etc.).

---

## 📊 Dashboard Key Metrics & Insights
Based on the underlying data engine programmed into this dashboard, here are the real-time market metrics displayed:

* **💰 Premium Market Volume:** The platform visualizes an extensive real estate portfolio with a Total Listed Price reaching **EGP 234.34 Billion**.
* **🏢 Scale of Listings:** The analytics engine processes and segments **21,634 active premium property listings** across Egypt.
* **📍 Regional Dominance:** **New Cairo** leads the analyzed market in concentration and valuation, followed closely by the **New Administrative Capital**.
* **🛏️ Inventory Structure:** The dataset reveals a heavy market focus on **3 Bedroom (3 BR)** configurations, which dominate the listings with **13.56K properties**, followed by **2 Bedroom (2 BR)** units with **4.59K properties**.
* **🏗️ Developer Insights:** Major developers like **TMG (Talaat Moustafa Group)**, **Mountain View**, and **Ora** are tracked dynamically to monitor market consolidation and developer share.

---

## 🛠️ Technical Stack & Frameworks
* **Frontend Architecture:** Clean, responsive HTML5 and semantic CSS3 featuring a modern dual-theme layout with a dedicated navigation sidebar.
* **Data Visualization:** **Chart.js Framework** used to render highly responsive, animated, and custom-styled bar charts, line graphs, and donut charts.
* **Data Layer:** Standardized **JavaScript JSON Objects** acting as a local lightweight data warehouse for sub-millisecond rendering speeds.
* **AI Tooling:** Prompt engineering and LLMs used during the initial ETL (Extract, Transform, Load) phase.

## 🚀 How to Run the Dashboard
Since this is a lightweight, serverless client-side application, running it is instant:
1. Clone or download the `egypt_real_estate_dashboard.html` file.
2. Double-click the file to open it directly in any modern web browser (Google Chrome, Microsoft Edge, Safari, Firefox).
3. No external dependencies, installations, or database connections are required!
